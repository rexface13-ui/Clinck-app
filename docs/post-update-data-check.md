# فحص وإصلاح البيانات بعد التحديث — برومت جاهز للنسخ

الزبون بيشغّل `update.bat` (أو زر التحديث) بس. هاد البرومت بيتنسخ لـ Claude Code
على جهاز الزبون بعدها، عشان يفحص البيانات ويصلّح اللي بلزم.

انسخ كل اللي تحت السطر.

---

انت شغال على نظام DentaFlow عند عيادة زبون — **بيانات حقيقية شغّالة، مش تجريبية**.

انعمل تحديث للنظام للتو. تحديث **الهيكل** (أعمدة وجداول جديدة) انطبق تلقائياً مع
التحديث. أما **إصلاحات البيانات القديمة** فما بتنطبق تلقائياً — موجودة بمجلد
`backend/database/migrations/repairs` ومنفصلة عن قصد.

مهمتك: **تفحص البيانات، تقولي شو لقيت، وبعد موافقتي تصلّح.**

## القواعد

1. **ممنوع تعدّل أو تحذف أي بيانات قبل ما تعرض عليّ وتاخد موافقة صريحة.**
   ابدأ بفحص قراءة بس.
2. لا تفترض ولا تخمّن — كل استنتاج لازم يكون مبني على استعلام فعلي شغّلته وشفت
   نتيجته. لو ما قدرت تتحقق من إشي، قول "ما قدرت" بدل ما تخمّن.
3. لو لقيت خلل، بلّغني **بالعدد والمبلغ وأسماء المرضى/الأطباء** المتأثرين.
4. أي إصلاح بتعمله، **خد نسخة احتياطية قبله**.
5. اكتبلي بالعربي.

## المسارات

- جذر النظام: المجلد اللي فيه `backend\` و `php83\`
- PHP: `php83\php.exe`
- تشغيل استعلام: من داخل `backend\` نفّذ
  `..\php83\php.exe artisan tinker <ملف.php>`
  (اكتب الاستعلامات بملف PHP مؤقت واستدعيه — لا تكتب SQL طويل داخل `--execute`
  لأن PowerShell بتكسره)
- قاعدة البيانات: PostgreSQL، بياناتها بملف `backend\.env`
- النسخ الاحتياطي: `..\php83\php.exe artisan backup:create`
  (بتنحفظ بـ `backend\storage\app\backups`)

# المرحلة ١ — جرد: شو لسا ما انطبق

نفّذ من داخل `backend\`:

```
..\php83\php.exe artisan migrate:status --pending
..\php83\php.exe artisan migrate:status --pending --path=database/migrations/repairs
```

- الأول لازم يطلع **فاضي**. لو فيه إشي معلّق، بلّغني فوراً ووقّف — معناها التحديث
  ما كمّل صح.
- التاني بيفرجيك إصلاحات البيانات المعلّقة. اقرا كل ملف منهم من مجلد `repairs`
  وافهم شو بيعمل بالضبط قبل ما تكمّل.

**ملاحظة:** `migrate:status` بترجّع exit code صفر بالحالتين، وكلمة "pending"
موجودة كمان بجملة "No pending migrations." — ميّز بالجملة نفسها مش بالكلمة.

# المرحلة ٢ — فحص البيانات (قراءة بس)

لكل فحص: اطبع **العدد**، و**المبالغ**، و**أسماء** المتأثرين إن وجد.

### ١) الفواتير مقابل كشف الحساب
لكل مريض لازم يطلع:
`مجموع (إجمالي الفاتورة − المسدّد منها) = رصيد المريض بكشف حسابه`

رصيد المريض = مجموع `patient_transactions` بحيث `charge` و `adjustment` موجب،
وأي نوع تاني سالب.

### ٢) حالة الفاتورة مقابل المسدّد
ما بصير فاتورة `paid` وفيها متبقي، ولا `unpaid` وهي مسدّدة، ولا `partial` وهي
صفر أو كاملة.

### ٣) أسنان محسوبة وظاهرة "مش منجزة"
صفوف `work_item_tooth_steps` اللي `completed_at` فيها `null` و `invoice_line_id`
**مش** `null`. لازم صفر. اطبع مجموع المبالغ لو في.

### ٤) حالة الجلسة مقابل أسنانها
جلسة `done` لازم كل أسنانها معلّمة منجزة، والعكس. تجاهل `cancelled`.

### ٥) أرقام أسنان وهمية
بجداول `work_item_teeth` و `work_item_tooth_steps` و `tooth_findings` و `notes`:
أي `tooth_number` مش من ترقيم FDI. الأرقام الصحيحة بـ
`backend\app\Support\Dental\FdiTeeth.php` — اقراها من هناك، لا تكتبها من راسك.

### ٦) عمولات أطباء بدون مصدر
`doctor_transactions` نوعها `commission`, و `tooth_finding_id` فيها `null`,
و `notes` فيها `null`, والمبلغ موجب.
اطبع العدد والمبلغ **لكل طبيب بالاسم**.

### ٧) أرصدة الصناديق
لكل صندوق: `balance` المخزّن لازم يساوي مجموع حركاته بـ `cashbox_transactions`.

### ٨) شيكات معلّقة
شيكات واردة حالتها مش `bounced` ومربوطة بمريض مش موجود، أو مبلغها صفر أو سالب.

# المرحلة ٣ — التقرير (وقّف هون)

اكتبلي:

- **سليم ✅** — الفحوصات اللي طلعت صفر
- **فيه خلل 🔴** — لكل واحد: شو الفحص، كم صف، كم مبلغ، مين المتأثر، وشو الأثر
  العملي على العيادة
- **مش متأكد ⚠️** — أي إشي ما قدرت تتحقق منه وليش
- **اقتراحك:** هل إصلاحات `repairs` المعلّقة بتغطي اللي لقيته؟ ولا في إشي بدو
  تدخّل يدوي؟

وبالآخر: **هل النظام آمن للاستخدام هلأ**، بجملة وحدة واضحة.

**استنى موافقتي قبل ما تعدّل أي إشي.**

# المرحلة ٤ — الإصلاح (بعد موافقتي بس)

1. **نسخة احتياطية أول** — `artisan backup:create`، وتأكد إنه الملف انكتب فعلاً
   (عدّ الملفات قبل وبعد). لو ما انكتبت، **وقّف**.
2. طبّق إصلاحات البيانات:
   `..\php83\php.exe artisan migrate --force --path=database/migrations/repairs`
   (أو شغّل `installer\migrate.bat` اللي بيعمل نفس الإشي مع تأكيد ونسخة)
3. **أعد كل فحوصات المرحلة ٢** واعرضلي **قبل/بعد** جنب بعض.
4. لو ضل خلل ما انحل بالإصلاحات التلقائية، **اعرض عليّ الحل المقترح قبل ما
   تنفّذه** — بالاستعلام اللي رح تشغّله والصفوف اللي رح تتأثر.

## بالآخر

اعطيني ملخص: شو انصلح، شو ضل، واسم النسخة الاحتياطية اللي أخذتها.
